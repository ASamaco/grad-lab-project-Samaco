# grad-lab-project-Samaco
Python simulation of phase plates and their effects on laser beam propagation

### Simulation of Phase Plates for Laser Beam Shaping

Student: Aaron Samaco

### Project Overview:

This project involves developing a Python simulation to investigate how optical phase plates affect laser beams. Phase plates modify the phase of an incoming beam, which can change its intensity distribution as the beam propagates through an optical system.

This project is related to my graduate research interests in femtosecond laser fabrication of phase plates for high-energy laser applications and coherent beam combining.

The goal is to create a numerical model that generates different phase profiles, applies them to a simulated laser beam, and visualizes the resulting optical field.
