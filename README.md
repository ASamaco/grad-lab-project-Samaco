# grad-lab-project-Samaco
Python simulation of phase plates and their effects on laser beam propagation

### Simulation of Phase Plates for Laser Beam Shaping

Student: Aaron Samaco

### Project Overview:

This project involves developing a Python simulation to investigate how phase plates affect laser beams. Phase plates modify the phase of an incoming beam, which can change its intensity distribution as the beam propagates through an optical system.

The goal is to create a numerical model that generates different phase profiles, applies them to a simulated laser beam, and visualizes the resulting optical field.

### Planned Data and Imaging Modality:

The project will use simulated data rather than experimental measurements.

The simulation will generate:

- Two-dimensional Gaussian laser beam profiles.
- Mathematical phase distributions representing different phase plates.
- Simulated propagated beam intensity distributions.
- Visual comparisons between the original and modified beams.
